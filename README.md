# 🚨 SIAR - Sistema de Información y Alerta Resiliente

## 📌 Descripción

Sistema de comunicación resiliente para cooperativas agrícolas...

## 🎓 Proyecto Académico

- **Curso:** Matemática Discreta - 4to Ciclo
- **Carrera:** Ingeniería de Software
- **Integrantes:** Steveen Maque Espinoza - Edwin Piero Badillo Castillo

## 🔬 Fundamentos Matemáticos Aplicados

- Unidad I: Lógica proposicional + Teorema de Bayes
- Unidad III: Teoría de grafos + Autómatas finitos
- Unidad IV: Códigos de Hamming + Criptografía básica

## 🚀 Instalación

```bash
git clone https://github.com/PendoVan/SIAR.git
cd SIAR
pip install -r requirements.txt
```

## 📊 Casos de Uso

1. Envío de alerta con corrección de errores
2. Cálculo de ruta más fiable
3. Validación de autenticidad de mensajes

## 🧪 Pruebas

```bash
pytest tests/
```
